# Definition of Done

A feature is done only when:
- domain behavior is implemented with typed models;
- persistence migration exists when required;
- API contract is documented/generated;
- permission/privacy implications are reviewed;
- unit/integration tests cover happy and negative paths;
- sensitive values do not enter normal logs;
- errors surface actionable user state;
- AI behavior uses versioned prompt/schema/model metadata;
- rule-driven behavior records rule provenance;
- UI does not pretend an unimplemented feature works;
- docs and TODO are updated.
