# UI / UX Specification

## Style
Modern, elegant, calm and information-dense. Desktop-first and responsive.

## Navigation
Dashboard, Inbox, Medical Events, Insurance, 730, Review Queue, Family, Settings.

## Dashboard
Filters by year/member. Cards for unprocessed docs, events, insurance candidates, incomplete claims, reimbursements, residual expenses, 730 totals, reconciliation differences and reviews.

## Inbox
Drag/drop upload, processing state, thumbnail, type, patient guess, date, amount, confidence and proposed event.

## Event workspace
Three-pane layout: documents/timeline, interactive graph, analysis/evidence/rules.

## Graph
Nodes for documents, people, events, expenses, medicines, claims, reimbursements and tax allocations. Edges expose relation, confidence, evidence and conflicts.

## Viewer
PDF/image preview beside extracted fields. Clicking a field highlights its page/bounding box where available.

## Review Queue
Keyboard-friendly resolution of patient conflict, uncertain AIC, multiple prescriptions/events, missing diagnosis/payment evidence, insurance/tax ambiguity, duplicates and pre-filled mismatch.

## Accessibility
Keyboard navigation, strong contrast and non-color-only state indicators.
