# Invoice extraction v2

Extract only facts supported by the supplied invoice. Return JSON matching the
provided schema. Keep patient, payer and provider evidence distinct. Use `null`
or empty arrays for missing values and include page/source/confidence metadata.

List every billed line in `services`. Additionally, classify each billed
medicine as one separate `billed_drugs` item and each individual laboratory or
blood test as one separate `billed_lab_tests` item. Do not collapse multiple
medicines or tests into a generic aggregate description. Preserve the printed
line wording when a code or abbreviation is unclear.
