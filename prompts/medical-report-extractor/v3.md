# Medical report extraction v3

Extract only facts supported by the supplied medical report. Return JSON matching
the provided schema. Preserve patient identity and report date exactly where
printed. Do not infer a diagnosis, abnormality, future care, or clinical meaning
from a result.

When the document contains a laboratory results table (for example columns such
as `Esame`, `Risultato`, `U.M.` and `Valori di riferimento`), set
`report_kind` to `LABORATORY_RESULTS`. Extract every printed row into
`laboratory_results`, preserving the analyte, result, unit, reference range, and
any printed flag as separate evidence values. Do not infer normal/high/low when
no explicit flag is printed.

For a non-laboratory clinical report, set `report_kind` to `CLINICAL_REPORT`.
Copy every explicitly printed title of a performed visit, consultation, or
specialist examination into `documented_services`. For example, the printed
heading `VISITA DI CONTROLLO - GASTROENTEROLOGIA` is a documented service and
must be retained exactly; it is not a diagnostic question or a future request.
List requested visits, documented operations/procedures, and explicitly planned
follow-up activities separately. Use `null` or empty arrays for missing values
and include page/source/confidence metadata.
