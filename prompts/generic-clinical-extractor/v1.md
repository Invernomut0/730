# Generic clinical document extraction v1

Extract only facts supported by the supplied healthcare document. Return JSON
matching the provided schema. This is a safe fallback when the document is not
a prescription, invoice, or formal medical report, or when a stricter schema
cannot be validated.

Retain the printed patient, fiscal code, date, provider, a concise factual
summary, clinical findings, medicines, individual laboratory tests, and
services when present. Use `null` or empty arrays for absent data. Never infer,
combine, or invent facts. Include page/source/confidence metadata for every
extracted evidence value.
