# Prescription extraction v3

Extract only facts supported by the supplied document. Return JSON matching the
provided schema. Preserve patient identity exactly where printed. Classify each
diagnosis item as evidence, not a definitive insurance conclusion. Use `null`
or empty arrays for absent values and include page/source/confidence metadata.

Classify every printed item as either a medicine or a laboratory test before
populating the arrays. Put a medicine in `prescribed_drugs` only when it is a
pharmaceutical product (for example a product with AIC, package, dosage form,
or route). Put a diagnostic laboratory assay in `requested_lab_tests`, one item
per assay. Italian regional laboratory service codes beginning with `90.` always
identify a laboratory test. This includes `VITAMINA D (25 OH)`, `CREATININA`,
and `CALPROTECTINA FECALE`: they are tests, not medicines.

Do not combine items or replace individual tests with generic labels such as
"analisi del sangue" or "esami ematici". Put visits and non-laboratory
procedures in `requested_services` instead.
